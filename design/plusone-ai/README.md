# PlusOne AI loading motion

Interactive motion study for the selected C logo: the numeral stays fixed while the outer ring and detached round dot rotate clockwise. Completing the loading state brings the orbit smoothly back to its upper-right resting position.

- `plusone-loading-motion.html`: standalone browser preview with its styles and runtime included. Open this file directly in a browser.
- `plusone-loading-motion.fragment.html`: editable source for the preview. After editing, regenerate the standalone file with the Codex Visualize export workflow.

The preview demonstrates loading, completion, replay, and 16 / 24 / 32 px sizes. It respects reduced-motion preferences. Controls use a simulated loading state; the preview is not connected to the application's actual asset loading, header, or browser favicon.

The standalone export includes fallback state storage for use outside Codex. No package installation or Next.js development server is required to open it.
